## Requirement

A new workflow, `.github/workflows/web-tests.yml`, runs the bUnit/xUnit v3 suite `src/AddressBook.Web.Tests` on GitHub Actions. It needs .NET 10 only: no SQL Server, no Node, no browsers. It publishes a test report, and a coverage report if approved.

No CI job runs these tests today. `build.yml` restores and builds the solution, which compiles the test project but never runs it, so the new workflow duplicates nothing.

## Approach

1. **Coverage extension (if approved).** The project runs on Microsoft.Testing.Platform 2.3.3, which `xunit.v3` 4.0.0 pulls in. VSTest `--collect` does not work under MTP, so use one of:
   - `Microsoft.Testing.Extensions.CodeCoverage` (Microsoft, free, closed-source license): `--coverage --coverage-output-format cobertura`.
   - `coverlet.MTP` (MIT): `--coverlet …`.

   Take the latest version on the MTP 2.x line. Pin it only if the MTP major line constrains it, with a comment per the pin contract in `Directory.Packages.props`. The extension registers itself through `Microsoft.Testing.Platform.MSBuild`; no code is needed.
2. **TRX.** xUnit v3 has a built-in `--report-xunit-trx`. Confirm with `dotnet test --project src/AddressBook.Web.Tests -- --help`. If it is missing, add `Microsoft.Testing.Extensions.TrxReport` and use `--report-trx`.
3. **Workflow shape**, modelled on `ui-tests.yml`:
   - `name: Web Component Tests`; triggers `push` and `workflow_dispatch` (decision 1).
   - `permissions: contents: read`; `concurrency` group `${{ github.workflow }}-${{ github.ref }}` with `cancel-in-progress`.
   - One job, `ubuntu-latest`, `timeout-minutes: 15`.
   - Steps: checkout; setup-dotnet with `dotnet-version: 10.0.x` (not `global-json-file`, because `global.json` pins no SDK) and the NuGet cache; `dotnet restore src/AddressBook.Web.Tests --locked-mode`; `dotnet build … -c Release --no-restore`; `dotnet test --project src/AddressBook.Web.Tests -c Release --no-build --results-directory TestResults -- --report-xunit-trx --coverage --coverage-output-format cobertura`; upload-artifact `web-tests-results` with `if: ${{ !cancelled() }}` and `retention-days: 30`.
   - Under the .NET 10 SDK, MTP-mode `dotnet test` takes the project through `--project`. The positional form may be rejected; check locally and fix the README quick start if so.
4. **SHAs.** Resolve each action tag to a commit SHA with `gh api repos/<owner>/<repo>/git/ref/tags/<tag>`. The existing workflows are not migrated in this change.
5. **Docs** as listed above.

## Decisions

Pending confirmation:

1. **Triggers.** Default: `push` and `workflow_dispatch`, like the other workflows. Alternatives: `paths` filter (`src/AddressBook.Web/**`, `src/AddressBook.Web.Tests/**`, `src/AddressBook.Contracts/**`, `src/Directory.*.props`, `global.json`, the workflow file), and/or `pull_request` to `main`.
2. **Coverage.** Yes or no; if yes, Microsoft CodeCoverage with Cobertura output (default) or `coverlet.MTP` (MIT). If no, only the TRX artifact ships and no package is added.
3. **Artifact retention.** 30 days, as the Playwright workflows.
4. **Separate workflow** (default, as the issue says) or a step in `build.yml`.
